# For agents

This repository is a catalogue of ways to make characters: [README.md](README.md) says what is where, how to take
something for a game and how to put something new here. The docs start at [docs/README.md](docs/README.md).

- **Take the way, not the character; copy, don't link.** A game copies what it takes into its own repository and
  changes it there. Characters here are examples: a game makes its own.
- **New things go beside, never over.** A new item or a better version is a new folder with the next free code and a
  line in its section's list; shared folders (`engine/`, `engine-full/`, `experiments/data/`) are not changed in
  place. Copied code is fine; don't generalise or pull out common code unless Pavel asks.
- **Only what is finished comes here**, shown on a page that runs from the repository's root, with its notes: what
  was done, how to repeat it, what is weak.
- **History is written always.** Every change gets a note in `docs/history/` — for a single commit or for a group of
  commits; for each commit is very good. What happens and why it happens: what was done, what called for it, what was
  decided and by whom, and how, so another agent can repeat it.
- **Requirements are kept.** What Pavel says matters goes into [docs/requirements.md](docs/requirements.md); read it
  before work; never drop or narrow what is there without asking him.
- **Keep what Pavel sends.** References and anything useful go into the repository (`docs/pictures/references/`,
  `docs/references.md`), and so do the thoughts and directions discussed (`docs/directions.md`).
