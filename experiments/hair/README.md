# Hair

A hairstyle is a set of parts; within a part every piece merges into one surface, so it reads as a few big shapes
with soft grooves. Parts: a scalp mass (the skull grown by a thickness, cut by a drawn five-point hairline, one side
can be shaved); locks swept along guide curves with a lens section, varying width, sharp or soft tips, wave, curls,
twist; helpers for a fall, a fringe, a braid, curls, buns and bands. Each lock keeps its guide curve so it can later
hang on a chain of joints from the Head bone. `styles.js` holds 14 hairstyles after Pavel's references.
